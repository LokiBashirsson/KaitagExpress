Сырой, без архитектуры, но рабочий
Работает без ORM(ПОКА ЧТО, В ДАЛЬНЕЙШЕМ ЧЕРЕЗ PRISMA ИЛИ TYPEORM) используется PostgreSQL и pool

без нодмон, с watch от node

Картинки из проекта можно удалить, они не связаны с проектом, картинки берутся из cloudinary, куда они и загружены бесплатно

С проектом связаны сайт и мобилка

Запуск:
npm run dev
